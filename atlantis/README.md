# Atlantis Development API — unofficial NeoForge port

This directory contains a port of [Atlantis Development](https://gitlab.com/atlantis-development/atlantis) to Minecraft 1.21.1 / NeoForge 21.1.265. It is **not** the unrelated ocean-dimension mod named Atlantis.

The original project is copyright Waterdude Studios Ltd and is dual licensed under MIT or LGPL-3.0; see [LICENSE-Atlantis.txt](LICENSE-Atlantis.txt). Original notices and attribution are retained. Port changes adapt build metadata, dependency declarations, and APIs for NeoForge 1.21.1.

The distributable file is `atlantis-9.0.0-local.2-all.jar`. The plain JAR omits shaded runtime dependencies. Pixelmon is optional for Atlantis at runtime but is needed to compile this source tree; download Pixelmon 9.4.2 separately into `libs/`.

Community fixes are welcome. Ongoing maintenance is not promised.
