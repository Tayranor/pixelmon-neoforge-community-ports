# Contributing

Community contributions are welcome for both projects.

For a bug report, include the affected mod and version, Pixelmon and NeoForge versions, the smallest reproduction steps, and the relevant log excerpt. Avoid uploading entire saves or personal account data unless necessary.

For a pull request, explain the behavior changed, test against Minecraft 1.21.1 / Pixelmon 9.4.2, and keep third-party assets and Pixelmon JARs out of the repository. For Atlantis changes, preserve upstream notices and its dual license. For the radar, do not copy source code or graphics from the original GameShark, whose 1.16.5 release states All Rights Reserved.

This is a best-effort community project. An open issue or pull request is not a promise of support, review, or a future release.
